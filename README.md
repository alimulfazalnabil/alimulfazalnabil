## Profile

I am an Infrastructure, Cloud Systems and DevOps Engineer with 7+ years of experience supporting enterprise IT environments, administering systems and networks, and improving operational reliability through automation.

My work spans cloud architecture, infrastructure as code, CI/CD, systems administration, machine learning, computer vision and robotics. I enjoy turning complex operational requirements into secure, maintainable and well-documented engineering solutions.

- **Infrastructure & Cloud:** Microsoft Azure, Windows Server, Linux, VMware, networking and identity
- **DevOps & Automation:** Terraform, Ansible, Docker, Kubernetes, GitHub Actions, Python and PowerShell
- **AI & Data:** Python, machine learning, LLM applications, RAG, PostgreSQL and data pipelines
- **Robotics & Computer Vision:** ROS 2, OpenCV, CARLA and embedded systems
- **Current focus:** Reliable cloud platforms, infrastructure automation, applied AI and robotics
